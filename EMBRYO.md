# Embryo Desktop Shell

Embryo Desktop Shell is Embryo-Zero's fork of [Tauri](https://github.com/tauri-apps/tauri) (commit c42354b, 2026-11-17). It is the app framework the Embryo-Zero desktop apps (Linux first, then Windows and Mac) are built with.

- Our changes live on the `embryo` branch. The original license files (LICENSE-APACHE-2.0, LICENSE-MIT, LICENSE.spdx) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
